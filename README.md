# Кітап оқу байқауы — онлайн платформа

Компания ішіндегі кітап оқу байқауына арналған уақытша сайт. Қатысушы QR-код арқылы кіреді, тіркеледі, кітапты оқиды, «Оқып бітірдім» деп белгілейді. Ұйымдастырушы әкімші панелінен барысын бақылайды және Excel есебін жүктейді.

> **Қазіргі күйі.** Тесттің ішкі бөлігі (сұрақтар, таймер, ұпай есептеу) әлі жасалған жоқ, ол кейін бөлек қосылады. Қазір тест бетінде тек «Тестті бастау» батырмасы тұр. Қалған бөліктің бәрі дайын: тіркелу, ЖСН арқылы кіру, кітап, оқу барысы, рейтинг беті, әкімші панелі, QR, Excel есебі.

| № | Не істеу керек | Қай жерде |

## 2. Файлдар

```
index.html          Басты бет: тіркелу, ЖСН арқылы кіру, қатысушының басты беті
book.html           Кітап беті (2/3)
test.html           Тест беті (3/3) — қазір тек батырма
result.html         «Менің нәтижем»
rating.html         Үздік 50 қатысушы
admin.html          Әкімші панелі
poster.html         Басып шығаруға арналған QR плакат (A4)
css/style.css       Барлық стиль
js/config.js        Apps Script сілтемесі осында қойылады
js/ui.js            Белгішелер, сұрау терезелері, хабарламалар
js/api.js           Сервермен байланыс, қайталау, оқиғалар кезегі
js/app.js           Қатысушы беттерінің логикасы
js/admin.js         Әкімші панелінің логикасы
data.json           Кітап пен жұмыс орындары (сайт бірінші ашылғанда тез жүктелуі үшін)
apps-script/Code.gs Сервер коды (Google Apps Script)
apps-script/appsscript.json  Apps Script баптауы (міндетті емес)
```

Сайтта build қадамы жоқ: файлдарды сол күйінде GitHub Pages-ке саласыз.

**Деректер қалай жүреді.** Сайт алдымен `data.json` файлын оқиды (тез, серверге жүктеме түспейді), сосын серверден жаңа баптауларды алады (кэште 2 минут тұрады). Тіркелу мен оқиғалар Apps Script арқылы Google Sheets-ке жазылады. Байланыс үзілсе, оқиғалар телефонда сақталып, байланыс қайта қосылғанда өзі жіберіледі.

## 3. Қадамдық орнату нұсқаулығы

### 3.1. Google Sheets және `setup()`

1. [sheets.new](https://sheets.new) ашып, жаңа кесте жасаңыз. Атауын қойыңыз, мысалы «Кітап байқауы — деректер».
2. Мәзірден **Кеңейтімдер → Apps Script** (Extensions → Apps Script) таңдаңыз.
3. Ашылған редактордағы `Code.gs` ішін түгел өшіріп, орнына репозиторийдегі `apps-script/Code.gs` файлының мазмұнын қойыңыз. Сақтаңыз (Ctrl+S).
4. Сол жақтағы тісті доңғалақ **Project Settings** → **Time zone** → `(GMT+05:00) Atyrau` екенін тексеріңіз. Уақыттар осы белдеумен жазылады.
5. Редакторға оралып, жоғарыдағы функция тізімінен `setup` таңдап, **Run** басыңыз.
6. Google рұқсат сұрайды: **Review permissions → аккаунтыңызды таңдаңыз → Advanced → Go to … (unsafe) → Allow**. Бұл қалыпты: скрипт сіздің кестеңізге жазу үшін рұқсат алады.
7. Кестеге оралыңыз. 6 парақ пайда болуы керек: `Participants`, `Books`, `Questions`, `Progress`, `Results`, `Settings`.

`setup()` функциясын қайта іске қосуға болады: ол бар деректерге тимейді, тек жетпей тұрғанын қосады.

### 3.2. Әкімші құпиясөзі (Script Properties)

1. Apps Script → **Project Settings** → төменде **Script Properties** → **Edit script properties → Add script property**.
2. Property: `ADMIN_PASSWORD`, Value: ұзын құпиясөз (кемінде 12 таңба).
3. **Save script properties**.

Құпиясөз кодта да, репозиторийде де болмайды. Оны өзгерту үшін осы жерде мәнін ауыстырсаңыз жеткілікті, қайта жариялау керек емес.
`SPREADSHEET_ID` және `TOKEN_SECRET` жолдарын `setup()` өзі қосады, оларға тимеңіз.

### 3.3. Web App ретінде жариялау

1. Apps Script → **Deploy → New deployment**.
2. Тісті доңғалақ → **Web app**.
3. **Execute as: Me**. **Who has access: Anyone**.
4. **Deploy** басып, **Web app URL** сілтемесін көшіріңіз. Ол `https://script.google.com/macros/s/…/exec` түрінде болады.

> **Маңызды.** Кейін `Code.gs` кодын өзгертсеңіз, өзгеріс өздігінен шықпайды. **Deploy → Manage deployments → қарындаш → Version: New version → Deploy** жасаңыз. Сонда сілтеме өзгермейді. «New deployment» жасасаңыз, сілтеме жаңарып, `config.js` файлын қайта түзетуге тура келеді.

### 3.4. Сілтемені `config.js` файлына қою

`js/config.js` ашып, `API_URL` мәнін ауыстырыңыз:

```js
API_URL: 'https://script.google.com/macros/s/AKfycb…/exec',
```

Бұл сілтеме құпия емес, оны репозиторийге сала беруге болады.

### 3.5. GitHub Pages

1. GitHub-та жаңа репозиторий жасап, осы папкадағы файлдарды жүктеңіз.
2. **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.
3. 1–2 минуттан кейін сайт `https://<аты>.github.io/<репозиторий>/` мекенжайында ашылады.

Папкадағы логотип файлдарын (`.jpg`, `.pdf`) сайт қолданбайды. Оларды репозиторийге салу міндетті емес.

### 3.6. Кітапты, жұмыс орындарын және атауды түзету

`https://…/admin.html` ашып, құпиясөзбен кіріңіз:

- **Кітаптар**: сынақ кітабының орнына нақты кітаптың атауын, авторын, сипаттамасын және сілтемесін қойыңыз. PDF-ті Google Drive-қа салып, «сілтемесі бар кез келген адам көре алады» етіп бөлісуге болады. Файл жеңіл болғаны дұрыс (10 МБ-тан аспасын).
- **Жұмыс орындары**: тізімді өз құрылымыңызға сай жазыңыз. «Басқа» нұсқасы өзі қосылады.
- **Баптаулар**: байқау атауы, көмек мәтіні, ЖСН тексеру режимі.

Осыдан кейін **Кітаптар → data.json жүктеу** басып, файлды репозиторийдегі `data.json` орнына салыңыз (міндетті емес, бірақ сайт бірінші ашылғанда тезірек жүктеледі).

### 3.7. QR-код

Әкімші панелі → **QR-код**. Сайт сілтемесін тексеріңіз (басты беттің мекенжайы болуы керек), сосын:
- **PNG ретінде жүктеу**: хабарландыруға, презентацияға қою үшін;
- **Плакатты ашу және басып шығару**: A4 плакат, үлкен QR және «Телефонның камерасымен оқыңыз» нұсқаулығы.

Басып шығарған плакатты өз телефоныңызбен оқып, сайт ашылатынын тексеріңіз.

## 4. Байқау алдындағы тексеру тізімі

**Орнату**
- [ ] `setup()` іске қосылған, 6 парақ бар.
- [ ] `ADMIN_PASSWORD` қойылған, әкімші панеліне кіру жұмыс істейді.
- [ ] `config.js` ішінде дұрыс сілтеме тұр. Сайттың жоғарғы жағында «серверге қосылмаған» деген сары жолақ жоқ.
- [ ] Уақыт белдеуі: Atyrau (GMT+5). Сынақ тіркелудің уақыты кестеде дұрыс көрінеді.

**Мазмұн**
- [ ] Сынақ кітабы нақты кітаппен ауыстырылған, сілтеме телефонда ашылады.
- [ ] Жұмыс орындарының тізімі дұрыс.
- [ ] Қазақ әріптері (ә, ғ, қ, ң, ө, ұ, ү, һ, і) барлық бетте дұрыс көрінеді.

**Сынақ (20 адаммен)**
- [ ] 20 адам өз телефонынан QR арқылы кіріп, тіркелді.
- [ ] Бір адам екінші рет тіркеліп көрді: жаңа жазба жасалмай, «Сіз бұрын тіркелгенсіз» деп кіргізді.
- [ ] 0-ден басталатын ЖСН кестеде 12 сан күйінде сақталды.
- [ ] Қате ЖСН (мысалы, 10 сан) қызыл мәтінмен түсінікті қате берді.
- [ ] «Кітапты оқу» және «Оқып бітірдім» басылды, `Progress` парағында оқиғалар пайда болды.
- [ ] Бет жаңартылғанда және телефон өшіп қосылғанда қатысушы тоқтаған жерінен жалғастырды.
- [ ] Ұшақ режимінде «Оқып бітірдім» басылды, байланыс қосылғанда оқиға серверге жетті.
- [ ] Әкімші панелінде: көрсеткіштер, іздеу, сүзгілер, ауыстырғыштар жұмыс істейді.
- [ ] Excel есебі жүктелді, Excel-де ашылды, графиктер көрінеді.

**Құрылғылар**
- [ ] Android (Chrome) және iPhone (Safari) телефондарында тексерілді.
- [ ] Компьютерде (Chrome, Edge) тексерілді: сол жақта мәзір, оң жақта қосымша карточкалар.
- [ ] Күн астында, далада экрандағы мәтін оқылады.

**Жүктемені сынау**
- [ ] 20 адам бір уақытта, бір минут ішінде тіркеліп көрді. Ешкімде қате шықпады.
- [ ] Қаласаңыз: компьютердегі браузерде сайтты ашып, F12 → Console ішінде мына кодты орындаңыз. Ол серверге 40 сұраныс қатар жібереді (дерек жазбайды):
  ```js
  Promise.all([...Array(40)].map(() => fetch(APP_CONFIG.API_URL + '?action=ping').then(r => r.json()).catch(() => 'қате')))
    .then(a => console.log('Сәтті:', a.filter(x => x.ok).length, '/ 40'));
  ```
  Бәрі немесе барлығына жуығы сәтті болуы керек.

**Соңында**
- [ ] Сынақ деректері өшірілді (6-бөлім).
- [ ] Кестеге тек ұйымдастырушылар кіре алады.

## 5. Жүктеме бойынша ұсыныстар

Google Apps Script бір уақытта шамамен 30 сұранысты ғана қатар орындай алады. Сайт осыған бейімделген: баптаулар кэштеледі, жазу операциялары қысқа және кезекпен орындалады, телефон сәтсіз сұранысты өзі қайталайды, сервер бос болмаса «Көп адам кіріп жатыр, 10 секундтан кейін қайта байқаймыз» деп көрсетеді.

Соған қарамастан, 4000 адамды бір минутта кіргізбеңіз:

1. **Хабарландыруды бөліктеп жіберіңіз.** Мысалы, бөлімшелер бойынша әр 15–20 минут сайын 300–500 адамнан. Сонда тіркелу бір сағатқа біркелкі тарайды.
2. **Тестті бір минутта бәріне ашпаңыз** (тест қосылған кезде). Тестке бір сәттік уақыт емес, бірнеше күндік аралық беріңіз немесе бөлімшелерді ауысыммен шақырыңыз.
3. **Жарияламас бұрын `data.json` файлын жаңартыңыз.** Сонда бірінші бет серверді күтпей ашылады.
4. **Байқау кезінде кестені қолмен өңдемеңіз**, әсіресе `Participants` парағын сұрыптамаңыз және жолдарды өшірмеңіз. Баптауларды әкімші панелі арқылы өзгертіңіз.
5. **Ауыстырғыштың әсері 2–3 минутқа кешігеді**: баптаулар серверде 2 минут, телефонда 3 минут кэште тұрады. Бұл жүктемені азайту үшін әдейі жасалған.

## 6. Сынақ деректері және оларды өшіру

**Не бар:**
- 1 сынақ кітабы: «Қара сөздер», Абай Құнанбайұлы. Сілтемесі жалған (`example.com`), оны міндетті түрде ауыстырыңыз.
- Жұмыс орындарының үлгі тізімі (7 жол).
- Тест сұрақтары әзірге жоқ: `Questions` парағы бос, тек тақырып жолы бар. Сұрақтар тест бөлімімен бірге кейін қосылады.

**Сынақ үшін жарамды ЖСН** (ойдан құрастырылған, бақылау саны дұрыс): `900101300017`.
Қатаң тексеруді уақытша өшіргіңіз келсе: әкімші панелі → Баптаулар → «ЖСН-ді қатаң тексеру» белгісін алып тастаңыз.

**Сынақтан кейін тазалау:**
1. *Сынақ қатысушыларын өшіру.* Apps Script редакторында функция тізімінен `clearParticipantData` таңдап, **Run** басыңыз. Ол `Participants`, `Progress`, `Results` парақтарындағы барлық жолды өшіреді. Кітаптар мен баптаулар сақталады. **Кері қайтарылмайды**, сондықтан тек сынақтан кейін немесе байқау біткен соң қолданыңыз.
2. *Сынақ кітабын өшіру.* Әкімші панелі → Кітаптар → мәліметін нақты кітапқа ауыстырыңыз немесе «Өшіру» басып, жаңасын қосыңыз → «Сақтау».
3. Тазалағаннан кейін сынаққа қатысқан адамдар сайтқа кіргенде автоматты түрде тіркелу бетіне оралады.

## 7. Excel есебі

Әкімші панелі → **Excel есебі → Excel есебін жүктеу**. Сервер уақытша Google кестесін құрады, оны `.xlsx` файлына айналдырады, сосын уақытша кестені себетке жібереді. Дайындауға 1 минутқа дейін кетуі мүмкін.

| Парақ | Ішінде не бар |
|---|---|
| Қорытынды | 6 үлкен көрсеткіш, воронка, күн бойынша тіркелу, жұмыс орны бойынша бөлініс, ұпай бөлінісі, үздік 10 |
| Қатысушылар | Толық тізім, күйі түспен боялған, тақырып бекітілген, сүзгі қосулы |
| Оқу барысы | Кім қашан бастады, қашан бітірді, қанша уақыт кетті |
| Тест нәтижелері | Орны, ұпай, дұрыс жауап, уақыт (тест қосылғанша бос) |
| Жұмыс орындары бойынша | Әр жұмыс орны: сандар, пайыздар, орташа ұпай, көрнекі жолақтар |

**Білу керек шектеулер:**
- **A4 альбомдық формат.** Google Sheets басып шығару баптауын `.xlsx` файлына жазбайды. Сондықтан екі жол бар: (а) Excel батырмасымен бірге шығатын **«Қорытынды бетті PDF ретінде жүктеу»** батырмасы — ол A4 альбомдық, бетке сыйдырылған, басып шығаруға дайын; (ә) Excel-де Page Layout → Orientation → Landscape және Scale to Fit → 1 page wide қойыңыз.
- **Воронка.** Google Sheets-те воронка графигі жоқ, оның орнына көлденең бағандық график қолданылған.
- **Ұпай бөлінісі.** Ұпайлар 10 аралыққа алдын ала бөлініп, бағандық графикпен көрсетілген.
- **Дерек жолақтары (data bars).** Google Sheets-те олар жоқ. Орнына түс градиенті және `█` таңбасынан жасалған жолақтар қолданылған, екеуі де Excel-де сақталады.
- **Қаріп.** Есепте Inter қойылған. Компьютерде Inter орнатылмаса, Excel оны ұқсас қаріппен өзі ауыстырады.
- **Графиктерді тексеріңіз.** Бірінші есепті жүктегенде Excel-де ашып, 4 графиктің де орнында екенін қараңыз. Google графиктерді `.xlsx`-ке өзі айналдырады, бұл қадамды код тексере алмайды.

Есепте ЖСН мен телефон нөмірлері бар. Файлды тек жауапты адамдарға беріңіз.

## 8. Қауіпсіздік және жеке деректер

**Не қорғалған:**
- Барлық кіріс деректері серверде қайта тексеріледі және тазаланады.
- `=`, `+`, `-`, `@` таңбасынан басталатын мәтін кестеде формула болып кетпейді.
- ЖСН мен телефон қатысушыларға ешқашан қайтарылмайды. Рейтингте тек аты-жөні, жұмыс орны және ұпай шығады.
- Әкімшілік әрекеттер токенсіз орындалмайды. Токен 4 сағатқа беріледі. Құпиясөз 10 рет қате жазылса, кіру 10 минутқа жабылады.
- Құпиясөз бен қол қою кілті тек Script Properties ішінде сақталады.

**Сіз істеуіңіз керек:**
1. **Кестеге кіруді шектеңіз.** Google Sheets → Share: тек ұйымдастырушыларды қосыңыз. «Anyone with the link» **өшірулі** болсын. Кестеде 4000 адамның ЖСН мен телефоны тұр.
2. **Apps Script жобасын бөліспеңіз.** Оған кіре алған адам құпиясөзді көре алады.
3. **Web App рұқсаты.** «Anyone» дегеніміз — сайттың серверге сұраныс жібере алуы. Кестенің өзіне рұқсат бермейді.

**Білу керек тәуекел: ЖСН арқылы кіру.** Талап бойынша қайта кіру тек ЖСН арқылы жасалған, құпиясөз де, код та жоқ. Демек, басқа адамның ЖСН-ін білетін кісі оның атынан кіріп, оның аты-жөні мен оқу барысын көре алады, «Оқып бітірдім» деп белгілей алады. Телефон нөмірі мен ЖСН бұл жағдайда да көрсетілмейді. Байқау жүлделі болса, жеңімпаздарды марапаттар алдында жеке басын растауды ұсынамыз.

**Байқау біткен соң (міндетті):**
1. Әкімші панелінен соңғы Excel есебін жүктеп, қорғалған жерге сақтаңыз.
2. Тіркелу мен тестті жабыңыз (жоғарыдағы екі ауыстырғыш).
3. Жеке деректерді өшіріңіз: Apps Script → `clearParticipantData` → Run. Немесе кестені түгел өшіріп, Drive себетін де тазалаңыз.
4. Web App-ты тоқтатыңыз: Deploy → Manage deployments → **Archive**.
5. Деректерді сақтау қажет болса (мысалы, есеп беру үшін), кестенің көшірмесін жасап, оған тек бір жауапты адамды қалдырыңыз және сақтау мерзімін белгілеңіз. ЖСН бағанын өшіріп сақтаған дұрыс.
6. Excel файлының артық көшірмелерін (пошта, мессенджер, жүктеулер папкасы) өшіріңіз.

## 10. Кейін қосылатын бөлік: тест

Тест бөлімін қосу үшін мыналар дайын тұр:
- `Questions` парағы (сұрақ, 4 нұсқа, дұрыс жауап) және `Results` парағы;
- баптаулар: `testOpen`, `testStart`, `testEnd`, `graceMinutes`, `testDurationMin`, `questionCount`, `attempts`, `readRequiredBeforeTest`;
- `Participants` парағындағы «Тестті бастады», «Тестті аяқтады», «Ұпай (%)», «Дұрыс жауап», «Тест уақыты (сек)» бағандары;
- рейтинг, «Менің нәтижем» беті, әкімші панелі және Excel есебі осы бағандарды оқиды. Ұпай жазылған сәтте бәрі өзі толады.

Қосу керегі: `js/app.js` ішіндегі `startTest()` функциясы (қазір тек хабарлама көрсетеді) және `Code.gs` ішіндегі екі серверлік әрекет — тестті бастау (сұрақтарды дұрыс жауапсыз, кездейсоқ ретпен беру) және тестті аяқтау (уақыт пен ұпайды серверде есептеу).

**Ұпай туралы келісім:** «Ұпай (%)» бағаны 0-ден 100-ге дейінгі пайыз ретінде есептеледі. Есептегі «70%-дан жоғары алғандар» және ұпай бөлінісі осыған негізделген.
